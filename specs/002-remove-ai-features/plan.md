# Implementation Plan: Complete Removal of AI Features & Pure Local-Only Operation

**Branch**: `002-remove-ai-features` | **Date**: 2026-09-03 | **Spec**: [spec.md](file:///home/halit/AndroidStudioProjects/Kora/specs/002-remove-ai-features/spec.md)  
**Input**: Feature specification from `/specs/002-remove-ai-features/spec.md`

## Summary

Completely eliminate all AI components, dependencies, UI cards, database entities, background generation trackers, and network permissions from Kora. The application transitions to a 100% offline-first, purely local tutoring management tool. Room database is migrated from version 8 to 9 by dropping the `ai_insights` table while strictly preserving all student records, lesson logs, homework assignments, and payment records. The Android `INTERNET` permission and `GEMINI_API_KEY` configurations are revoked, and all obsolete AI localization strings are removed across English, Turkish, and German.

## Technical Context

**Language/Version**: Kotlin 2.3.0, JVM target 17  
**Primary Dependencies**: Jetpack Compose + Material 3, Hilt 2.58, Jetpack Navigation Compose 2.9.6, Room 2.8.4  
**Storage**: Room (local SQLite, offline-only per Constitution Principle I, migrated v8 → v9)  
**Testing**: JUnit 4.13.2, kotlinx-coroutines-test 1.10.2, MockK 1.13.13, compose-ui-test-junit4  
**Target Platform**: Android API 26+ (Min SDK 26, Target/Compile SDK 36)  
**Project Type**: Mobile app (Android, Jetpack Compose)  
**Performance Goals**: Instant UI rendering (< 50ms) without AI generation delays or network calls; reduced memory footprint  
**Constraints**: 100% offline-only, zero network permissions, zero cloud dependencies, non-destructive data migration for core tables, linguistic parity (EN/TR/DE)  
**Scale/Scope**: Standalone single-device local tutor management
